# CrossCulture Community

Website for CrossCulture Community (크로스컬처 커뮤니티) and CrossCulture
Community Foundation — a movement building the Museum of the Bible Korea in
Seoul and online discipleship training, honoring the Bible as the shared
heritage of all humanity.

Founded by Rev. Dr. Bill R. Majors.
